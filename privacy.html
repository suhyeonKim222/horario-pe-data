Datos en tu dispositivo

SinCruce funciona sin cuentas. La app no recopila ni envía al desarrollador datos personales, horarios guardados, calificaciones ni texto que importes. Tampoco usa SDK de publicidad, analítica o rastreo. Los planes, notas, preferencias y catálogos descargados se guardan en SQLite en tu dispositivo. El widget y los recordatorios opcionales usan datos locales. La beta no realiza compras.

Catálogo público y exportación

Para actualizar el catálogo, la app solo descarga archivos JSON públicos de horarios alojados en GitHub Pages. La solicitud no incluye tus planes, notas ni identificadores de cuenta. GitHub puede registrar la dirección IP de la conexión por seguridad, según su documentación de GitHub Pages. Puedes usar los catálogos guardados sin conexión. Si eliges compartir una imagen de tu horario, Android la entrega a la aplicación que selecciones.

Eliminar tus datos y contactarnos

Para borrar todos los datos locales, desinstala SinCruce o ve a Ajustes de Android → Aplicaciones → SinCruce → Almacenamiento y elige borrar datos. Las copias que hayas exportado a otra aplicación se gestionan desde esa aplicación.

Para consultas sobre privacidad, usa el canal de contacto del proyecto. Es público. Evita publicar información personal.

Privacy policy in English

Data on your device

SinCruce works without accounts. The app does not collect or send personal data, saved timetables, grades, or imported text to the developer. It uses no advertising, analytics, or tracking SDKs. Plans, grades, preferences, and downloaded catalogs are stored locally in SQLite. Optional reminders and the home screen widget use local data. The beta has no purchases.

Public catalog and exports

To refresh the catalog, the app only downloads public timetable JSON hosted on GitHub Pages. These requests contain no plans, grades, or account identifiers. GitHub may log the connection’s IP address for security, as described in its GitHub Pages documentation. Saved catalogs work offline. If you choose to share a timetable image, Android passes the export to the app you select.

Deleting data and contacting us

To remove all local data, uninstall SinCruce or open Android Settings → Apps → SinCruce → Storage and clear app data. Manage any copies exported to another app in that app.

For privacy questions, use the project contact channel. It is public. Please keep personal information out of posts.
